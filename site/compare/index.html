BotD checks automation signatures. Agent or Human adds live evidence changes, expiry, and analytics history—and can use BotD as an optional evidence source.

Use BotD alone when you need a browser automation check. Choose Agent or Human when your product needs to follow evidence over time, observe cooperative host or tool activity, and preserve that context in analytics.

No accuracy victory claimed. We have not established higher detection accuracy than BotD. Interaction heuristics are experimental; declarations and tool use do not authenticate an AI agent. Free, MIT-licensed, client-side detection is shared ground.

A testable difference
An unchanged browser environment can contain new evidence: your host explicitly starts an agent action, releases it, or a WebMCP tool executes. You need timestamps, listeners, expiry, and the exposure-time segment to interpret what follows.
The automated test suite covers those transitions, negative BotD results, provider failure, stale-result expiry, and cleanup. These are contract tests, not human-versus-agent accuracy benchmarks.

import { load } from '@fingerprintjs/botd';
import { createSessionMonitor, connectBotD,
  createSessionHistory } from 'agent-or-human';

const monitor = createSessionMonitor();
const history = createSessionHistory(monitor);
const detector = await load({ monitoring: false });
const botd = connectBotD(monitor, detector);
await botd.refresh(); // recollects; evidence expires after 60 seconds

monitor.addEventListener('statechange', event => {
  console.log(event.previousState, event.state);
});
console.log(history.getSummary());

// On unmount: history.stop(); botd.stop(); monitor.stop();
